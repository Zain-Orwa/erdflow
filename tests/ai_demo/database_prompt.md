# University database — AI demo prompt

Design a **conceptual database model** for a university using ERDFlow's actual modeling capabilities.

Include: Student, Course, Instructor, Department, Enrollment.
Represent Student–Course enrollment with appropriate M:M semantics; choose and explain whether Enrollment should be modeled as an associative relationship/entity. Provide identifiers, meaningful attributes, relationship cardinalities, optionality, and assumptions. Avoid inventing features or relationships without documenting assumptions.

Return **structured model data**, not coordinates, image pixels, SQL, or diagram screenshots. The native ERDFlow model validator and converter own correctness checks, Conceptual → Relational Schema conversion, and rendering.

This prompt is a fixture for an experiment; no AI calls are executed by the initial scaffold.
